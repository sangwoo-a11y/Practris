# Practris

테트리스 조작과 나만의 빌드를 연습하는 한국어 홈페이지입니다.

## 실행

Node.js 20 이상에서 별도 의존성 설치 없이 실행할 수 있습니다.

```sh
npm run dev
```

기본 포트는 5173이며 `PORT` 환경 변수로 변경할 수 있습니다.

- `npm run build`: `dist/`에 정적 배포 파일을 생성합니다.
- `npm test`: 충돌, 줄 지우기, 7-bag, 저장 데이터 및 하위 배포 경로 검증을 실행합니다.

홈페이지의 모드 카드는 자유 연습, 단계별 설계 연습, 빌드 에디터로 연결됩니다.

- 이동: 방향키, 90° 회전: ↑/X 및 Z, 180° 회전: A, 하드 드롭: SPACE, 홀드: C/Shift, 일시정지: ESC. 한글 IME에서도 물리 키 위치로 처리합니다. 연습 선택 뒤 초점은 보드로 돌아옵니다.
- 조작 설정은 시작 화면에만 있습니다. ARR/DAS/DCD와 SDF를 바꾸면 즉시 적용되고 브라우저에 저장됩니다. 적용 버튼도 지원합니다. ARR 0은 DAS 후 벽까지 즉시 이동, DCD는 회전/새 블록 뒤 횡이동 대기, SDF ∞는 소프트 드롭 즉시 바닥 도달입니다. 조작 반복은 OS 키 반복과 독립적입니다.
- 6–3 Stacking: 빈 보드와 무작위 7-bag에서 자유롭게 쌓습니다. 첫 미노부터 현재 보드의 도달 가능한 후보와 다음 한 수를 비교해 7열 우물 유지·빈칸·양쪽 높이 균형 기준으로 추천합니다. 4줄 클리어 뒤에도 보드와 NEXT를 유지하며 계속 쌓습니다. 후보 보기·자동 분석·한 수 되돌리기도 지원합니다. 오른쪽 3열의 실제 공간과 남은 NEXT·홀드로 조합을 확인해 추천 점수에 반영하고, J→O→L / J→S→L / J→Z→L을 직접 쌓는 연습으로 연결합니다.
- T-spin: 싱글·더블·트리플 혼합으로만 진행합니다. 종류 선택은 없으며 좌우 반전·높이·가비지 기반을 조합합니다. 작은 고정 목록을 순서대로 반복하지 않으며 세션 내 지형 중복을 피합니다. 마지막 회전, 3코너 점유, 전면 코너와 실제 클리어 줄 수를 확인해 미니를 목표 싱글로 잘못 처리하지 않습니다.
- 퍼펙트 설계: 자유 풀이 또는 PCO 기본형·PCO I 보류·MKO T 보류 PC를 선택합니다. 정형 방식은 빈 보드부터 10미노를 놓거나 준비된 보드의 3/4미노 마무리만 연습할 수 있습니다. 방식 한 수 힌트는 기본으로 숨기며, 선택 방식 학습에서 bag·홀드 설계로 연결합니다. 자유 풀이는 빈 보드에서 정답 위치 없이 풉니다. 준비된 예시와 다른 배치도 허용하며, 실제로 보드가 비면 성공합니다. 첫 7개는 7종이 한 번씩 나오며 NEXT는 5개입니다. 첫 미노를 놓기 전부터 실제 보드에서 현재 미노·홀드의 가능한 착지 위치를 자동 분석하고, 추천 위치를 금색 윤곽으로 표시합니다. 다른 위치에 놓으면 그 보드에서 다시 계산하며 자동 분석은 끌 수 있습니다. 예시와 다른 풀이도 분석하며 후보별 다음 한 수의 배치 수와 미리보기를 제공합니다. 한 수 되돌리기는 보드·현재 미노·NEXT·홀드·통계를 함께 복원합니다.
- 6–3와 퍼펙트는 현재 보드의 추천 한 수를 금색 윤곽으로 표시합니다. 퍼펙트의 후보 분석은 별도 창에서 보며 실제 게임판을 바꾸지 않습니다. 성공 시 자동으로 다음 과제로 이어지고, 실패 시 현재 단계를 다시 시도합니다. 연습에서는 계획할 시간을 주기 위해 자동 중력/자동 잠금을 사용하지 않으며 SPACE로 확정합니다. 별도 설명 패널 없이 보드에서 목표와 순서를 확인합니다. 다른 빌드 버튼으로 과제를 건너뛸 수 있습니다.
- 에디터: 미노는 팔레트 클릭으로만 선택합니다. X/↑는 시계 회전, Z/Q는 반시계 회전, A는 180° 회전입니다. B 또는 점 버튼은 칸 단위 브러시로 전환합니다. 점 모드는 드래그와 덮어쓰기를 지원합니다. 우클릭은 미노 모드에서 전체 모양, 점 모드에서 한 칸을 지웁니다. 배치 취소, 로컬 저장/불러오기, 만든 빌드로 연습하기를 지원합니다.
- 이전 칸 단위 빌드도 불러올 수 있습니다. 미노 구분 정보가 없는 빌드는 한 칸씩 삭제됩니다.

모바일에서는 화면 버튼과 팔레트로 조작할 수 있습니다. 90° 회전은 SRS 벽차기를 지원하며, 180° 회전은 자체 킥 규칙을 사용합니다. 점수 계산·랭킹이나 모든 퍼펙트 클리어 오프너는 제공하지 않습니다. 빌드는 현재 브라우저에 저장됩니다.

픽셀 폰트: [Galmuri](https://github.com/quiple/galmuri) 2.40.3, SIL OFL 1.1. 폰트와 라이선스는 `assets/`에 포함되어 외부 CDN 없이 로드됩니다.

각 설계 과제는 자체 7-bag에서 시작합니다. 계획된 배치 순서도 실제 bag 규칙을 지키며 남은 미노는 NEXT에 유지됩니다. 연습 모드의 홀드 교환은 순서 복구를 위해 반복 교환을 허용하고, 자유 연습은 한 미노당 한 번만 허용합니다. 홀드에서 미노를 복제하지 않습니다. 설계용 카탈로그와 넣기용 지형은 `lesson-data.js`에 있고, 전체 카탈로그를 테스트합니다.

가이드북은 시작 화면과 연습 화면에서 열 수 있습니다. 연습 화면에서 열면 현재 모드와 선택한 PC 방식·시작 지점 또는 빌드·학습 방식에 대한 설명을 먼저 보여줍니다. 기본 규칙, T-spin 싱글/더블/트리플 도해, 6–3, 퍼펙트, 에디터를 설명합니다. 퍼펙트 풀이 예시는 한 단계씩 확인하며 실제 판이나 NEXT를 바꾸지 않습니다. 책을 읽는 동안 게임 입력과 시간이 멈춥니다.

Hard Drop 카테고리는 가이드북의 외부 참고 링크입니다. T-spin 넣기 지형은 자체 검증 카탈로그이며, 빌드 학습은 공개 저장소의 오프너 도식과 엔진 검증을 기준으로 합니다. 원문 사이트를 실시간 조회해 후보를 가져오지는 않습니다. 빌드 학습의 도식 출처는 `docs/build-courses.md`에 있습니다.

## 현재 보드에서 다음 배치 분석

`다음 배치 경우`는 첫 미노를 놓기 전부터 사용할 수 있습니다. 현재 위치에서 좌우 이동·소프트 드롭·SRS 90° 회전·앱의 180° 회전으로 도달 가능한 착지를 탐색하고, 같은 네 칸을 차지하는 결과는 중복 제거합니다. 한 번의 홀드 대안도 분리해 보여줍니다. 각 후보 뒤에는 추가 홀드 없이 바로 다음 미노가 갈 수 있는 위치를 계산합니다. 여기의 수는 **두 수 이내의 유효한 배치 수**이며, 전체 PC 완성 해법의 총수가 아닙니다. 바로 PC가 완성되는 후보는 구분합니다. 계산은 Web Worker에서 실행하고, 읽는 동안 게임을 멈추며 닫으면 이전 상태로 돌아갑니다.

## 직접 쌓는 빌드 학습

상단 빌드 학습에서 TKI 3, DT Cannon, C-Spin 토대, Albatross Special, Perfect Clear Opener를 빈 보드부터 직접 쌓습니다. 빌드의 정의·장점과 학습 범위를 설명하고, Opener 32개와 중반 25개를 합친 57개 기존 변형과 12개 퍼펙트 방식 과정을 합친 69개 기본 사례를 자동으로 섞어 제공합니다. 중반은 TSD 지붕·TST 진입로·스키밍 후 TSD·6–3 오른쪽 3열 조합을 다룹니다. 현재 단계의 목표 위치와 배치 이유를 보여주고, 실제 이동·회전·SPACE 입력으로 놓으면 다음 단계로 이어집니다. 따라 쌓기에서 다른 위치는 보드와 NEXT를 바꾸지 않고 재시도하며, 목표 숨기기·한 수 전·다시 쌓기를 지원합니다. `#learn/dt`처럼 바로 열 수 있습니다. 변형 선택 UI 없이 같은 빌드 안의 방향·순서·지형 사례를 섞어서 하나씩 제공합니다. 완료 후 남은 사례로 자동 이동하고 모두 진행하면 같은 분류의 다음 빌드로 이어집니다. 자동 넘김을 끌 수 있고 완료 수를 유지합니다. bag 판단 방식은 목표를 처음에 숨기고 다양한 실제 7-bag과 홀드로 같은 형태를 설계합니다. 같은 단계의 다른 유효한 선택은 남은 목표를 다시 계산해 이어갑니다. bag 판단에서는 모든 유효한 배치를 고정해 보존하며, 형태를 벗어나면 안내하고 실제 T-spin·PC·7열 I 클리어 목표를 계속 판정합니다. 되돌리기는 형태 진행과 목표 판정 상태도 복원합니다. 선택한 형태가 가능한 bag 과제이며 모든 순서에서 성공하는 형태라는 뜻은 아닙니다. 각 과정의 정확한 범위와 도식 참고 자료는 [docs/build-courses.md](docs/build-courses.md)에 있습니다.

## 현재 보드에 맞춘 추천

배치 후보는 실제 보드에서 SRS/180° 회전까지 포함해 계산합니다. 추천은 보이는 NEXT 최대 5개와 홀드로 확인된 PC 경로를 우선하며, 찾지 못하면 내부 빈칸·높이·표면 굴곡을 기준으로 정렬합니다. 후보 창에서는 각 배치 뒤 다음 미노의 위치를 넘겨 보고, PC 경로가 확인된 후보는 끝까지 단계별로 볼 수 있습니다.

추천을 위한 PC 경로 탐색은 시간·노드 수를 제한하고, 남은 필요 미노가 적은 상황에서는 SRS 경로를, 그 밖에는 회전 후 수직 드롭하는 경로를 탐색합니다. 따라서 PC 경로 미확인은 불가능 판정이 아니며, 모든 PC 해법 또는 전역 최적해를 보장하지 않습니다. 화면의 후보 수는 도달 가능한 착지 수이며 PC 완성 해법의 총수가 아닙니다. 연산은 Worker에서 실행해 플레이를 멈추지 않습니다. 후보 창을 읽는 동안만 입력과 시간이 멈춥니다.

후보의 출처, PC의 BFS/DFS 탐색 및 점수식, 6–3의 두 수 평가와 제한은 [추천 알고리즘](docs/recommendations.md)에 설명합니다.

선택할 수 있는 PCO/MKO 방식의 준비·마무리 범위와 도식 출처는 [퍼펙트 방식](docs/perfect-methods.md)에 있습니다. 이 선택은 정형 빌드 선택이며 현재 보드의 PC 탐색은 기존 자체 BFS/DFS를 사용합니다.
