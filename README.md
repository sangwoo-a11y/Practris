# Practris

테트리스 조작과 나만의 빌드를 연습하는 한국어 홈페이지입니다.

## 실행

Node.js 20 이상에서 별도 의존성 설치 없이 실행할 수 있습니다.

```sh
npm run dev
```

기본 포트는 5173이며 `PORT` 환경 변수로 변경할 수 있습니다.

- `npm run build`: `dist/`에 정적 배포 파일을 생성합니다.
- `npm test`: 충돌, 줄 지우기, 7-bag, 저장 데이터 및 하위 배포 경로 검증을 실행합니다.

홈페이지의 모드 카드는 자유 연습, 단계별 설계 연습, 빌드 에디터로 연결됩니다.

- 이동: 방향키, 90° 회전: ↑/X 및 Z, 180° 회전: A, 하드 드롭: SPACE, 홀드: C/Shift, 일시정지: ESC.
- 조작 설정: ARR(0이면 DAS 후 벽까지 즉시 이동), DAS, DCD(회전·새 블록 뒤 횡이동 대기), SDF(소프트 드롭 배속/∞). 브라우저에 자동 저장됩니다. 키 반복은 OS 설정과 독립적으로 동작하며, 접지 후 잠금 대기는 450ms입니다.
- 설계 연습: 목표 위치와 단계별 안내를 보며 4줄 우물, 퍼펙트 클리어, T 홈을 만듭니다. 성공하면 다음 과제로 자동 진행하고, 잘못 놓으면 현재 단계에서 재시도합니다. 시간 제한 없이 계획하며 놓을 수 있고, 소프트/하드 드롭은 직접 조작합니다.
- 퍼펙트 클리어: 2 × 4 틈 채우기 → 빈 보드에 O로 직사각형 만들기 → I/O로 2 × 10 분할하기. 단계별 배치 입문 과정이며 모든 PC 오프너나 해법 탐색기를 제공하는 것은 아닙니다.
- 에디터: 팔레트에서 미노를 골라 X/Z/A 또는 버튼으로 회전하고, 미리보기를 확인한 후 클릭으로 모양 전체를 배치합니다. 우클릭은 미노 전체 삭제, 배치 취소 버튼은 최근 편집 취소입니다. 겹치거나 보드를 벗어나는 배치는 막습니다. 저장/불러오기와 만든 빌드로 연습하기를 지원합니다.
- 이전 버전의 칸 단위 빌드도 불러올 수 있습니다. 해당 빌드는 미노 구분 정보가 없어 한 칸씩 삭제됩니다.

모바일에서는 화면 버튼으로 플레이하고 회전 버튼으로 빌드를 편집할 수 있습니다.

회전은 기본 수평 벽차기이며 공식 SRS 및 T스핀 점수 판정은 포함하지 않습니다. 빌드는 현재 브라우저에만 저장됩니다.

픽셀 폰트: [Galmuri](https://github.com/quiple/galmuri) 2.40.3, SIL OFL 1.1. 폰트와 라이선스는 `assets/`에 포함되어 외부 CDN 없이 로드됩니다.
