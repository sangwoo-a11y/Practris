# Practris

테트리스 조작과 나만의 빌드를 연습하는 한국어 홈페이지입니다.

## 실행

Node.js 20 이상에서 별도 의존성 설치 없이 실행할 수 있습니다.

```sh
npm run dev
```

기본 포트는 5173이며 `PORT` 환경 변수로 변경할 수 있습니다.

- `npm run build`: `dist/`에 정적 배포 파일을 생성합니다.
- `npm test`: 충돌, 줄 지우기, 7-bag, 저장 데이터 및 하위 배포 경로 검증을 실행합니다.

홈페이지의 모드 카드는 자유 연습, 단계별 설계 연습, 빌드 에디터로 연결됩니다.

- 이동: 방향키, 90° 회전: ↑/X 및 Z, 180° 회전: A, 하드 드롭: SPACE, 홀드: C/Shift, 일시정지: ESC. 한글 IME에서도 물리 키 위치로 처리합니다. 연습 선택 뒤 초점은 보드로 돌아옵니다.
- 조작 설정은 시작 화면에만 있습니다. ARR/DAS/DCD와 SDF를 바꾸면 즉시 적용되고 브라우저에 저장됩니다. 적용 버튼도 지원합니다. ARR 0은 DAS 후 벽까지 즉시 이동, DCD는 회전/새 블록 뒤 횡이동 대기, SDF ∞는 소프트 드롭 즉시 바닥 도달입니다. 조작 반복은 OS 키 반복과 독립적입니다.
- 6–3 Stacking: 빈 보드에서 왼쪽 6열/7열 우물/오른쪽 3열을 설계합니다. 기초 과제 뒤에는 일곱 종류 미노를 섞은 과제를 반복합니다.
- T-spin 빌드 설계: 빈 보드에서 받침, 바닥, 벽, 지붕을 쌓고 실제 회전 진입으로 T-spin double을 완성합니다.
- T-spin 넣기: 완성된 홈에 회전으로 진입합니다. 성공하면 좌우·높이가 다른 6개 패턴을 순환합니다. 마지막 회전과 T 중심의 3코너 점유를 확인합니다.
- 퍼펙트 설계: 모든 과제가 빈 보드에서 시작합니다. O 기초 뒤에는 J/L·I·O로 2 × 10을 채우는 과제를 진행합니다.
- 설계 과제는 첫 미노부터 전체 예정 위치를 옅게, 현재 위치를 밝게 표시합니다. 성공 시 자동으로 다음 과제로 이어지고, 실패 시 현재 단계를 다시 시도합니다. 연습에서는 계획할 시간을 주기 위해 자동 중력/자동 잠금을 사용하지 않으며 SPACE로 확정합니다. 목표 표시를 끄고 복습할 수 있습니다.
- 에디터: T/I/O/S/Z/J/L 키 또는 팔레트로 미노를 선택합니다. X/↑는 시계 회전, Q는 반시계 회전, A는 180° 회전입니다. B 또는 점 버튼은 칸 단위 브러시로 전환합니다. 점 모드는 드래그와 덮어쓰기를 지원합니다. 우클릭은 미노 모드에서 전체 모양, 점 모드에서 한 칸을 지웁니다. 배치 취소, 로컬 저장/불러오기, 만든 빌드로 연습하기를 지원합니다.
- 이전 칸 단위 빌드도 불러올 수 있습니다. 미노 구분 정보가 없는 빌드는 한 칸씩 삭제됩니다.

모바일에서는 화면 버튼과 팔레트로 조작할 수 있습니다. 90° 회전은 SRS 벽차기를 지원하며, 180° 회전은 자체 킥 규칙을 사용합니다. T-spin mini/full 점수 계산이나 모든 퍼펙트 클리어 오프너는 제공하지 않습니다. 빌드는 현재 브라우저에 저장됩니다.

픽셀 폰트: [Galmuri](https://github.com/quiple/galmuri) 2.40.3, SIL OFL 1.1. 폰트와 라이선스는 `assets/`에 포함되어 외부 CDN 없이 로드됩니다.
