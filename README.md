# Practris

테트리스 조작과 나만의 빌드를 연습하는 한국어 홈페이지입니다.

## 실행

Node.js 20 이상에서 별도 의존성 설치 없이 실행할 수 있습니다.

```sh
npm run dev
```

기본 포트는 5173이며 `PORT` 환경 변수로 변경할 수 있습니다.

- `npm run build`: `dist/`에 정적 배포 파일을 생성합니다.
- `npm test`: 충돌, 줄 지우기, 7-bag, 저장 데이터 검증을 실행합니다.

홈페이지의 시작 버튼과 모드 카드는 연습실로 연결됩니다. 자유 연습, T스핀 배치/4줄/퍼펙트 클리어 프리셋, 빌드 편집 및 브라우저 로컬 저장을 지원합니다. 방향키로 이동, ↑/X와 Z로 회전, SPACE로 하드 드롭, C로 홀드, ESC로 일시정지합니다. 모바일에서는 화면 버튼으로 조작할 수 있습니다.

회전은 기본 수평 벽차기이며 공식 SRS 및 T스핀 점수 판정은 포함하지 않습니다. 빌드는 현재 브라우저에만 저장됩니다.
